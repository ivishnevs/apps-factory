1. Inputs on one sheet or block (prices, volumes, growth, costs), calculations separate, results last; no hard-coded numbers in formulas.
2. Monthly for the first year, then yearly; revenue, cost of revenue, operating costs, cash, runway.
3. Three scenarios (low, base, high) from the same model by changing inputs only.
4. Check it: totals add up, signs are right, a sanity line per section.
5. This is a planning tool, not financial advice; say so in the summary and list the riskiest assumptions.
