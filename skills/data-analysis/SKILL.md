1. Write the analysis as a script or notebook in the repository so it can be run again; never edit numbers by hand.
2. Check the data first: rows, columns, types, missing values, duplicates, outliers, the time range.
3. Answer the question asked with the simplest method that works; state the method.
4. Show results as small tables and charts with units and the period; round sensibly.
5. Say what the data cannot tell (sample size, bias, missing segments) and what you would collect next.
